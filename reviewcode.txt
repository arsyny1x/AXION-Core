What this app already does well
Most React listeners have cleanup. PlayerService generation-guards Tauri listen(). Logs, notifications, and inventory caches have caps. Heartbeat UI events are throttled to 10s in Rust. LiveTime shares one interval.
Highest impact
H1: disposeLuaApi is fire-and-forget under StrictMode
src/App.tsx + luaApiService.ts

App unmount cleanup calls void disposeLuaApi() without awaiting. React StrictMode unmounts then remounts immediately, so getLuaApi() can create a second Wasmoon runtime while the first WASM engine is still closing. Two LuaFactory/WASM heaps can stay alive in Dev.

Serialize init/dispose with a generation token; await dispose before creating a new module; skip dispose on StrictMode fake-unmount or use a process-lifetime singleton that is not disposed from App effect cleanup.

H2: New LuaFactory on every Server Script load
src/services/serverScriptsService.ts

loadServerScript() does new LuaFactory() then createEngine() for each load/reload. LuaFactory typically fetches and instantiates WASM. Old engines are closed, but factories are dropped with no dispose. Reloading scripts during a session repeats WASM allocation.

Reuse one shared LuaFactory (like WasmoonLuaRuntime). Close only the engine. Optionally cache compiled engines by source hash (already skipped when source unchanged).

H3: Lua timeout does not stop the engine
src/lua-api/runtime/WasmoonLuaRuntime.ts

executeScript races doString against setTimeout. On timeout the Promise rejects but engine.doString keeps running. WASM/Lua continues allocating until the script finishes or the engine is later closed. Server scripts use functionTimeout: 4000; the shared runtime does not.

Use Wasmoon functionTimeout / interrupt; on timeout call engine.global.close() and drop the engine from the map.

Hot paths (why the UI can hitch)
Agent heartbeat → React
Rust emits axion-agent-heartbeat about every 10s per agent. PlayerService.emit() clones all players. AgentsPanelsetPlayers(snapshot.players) and PlayersPagesetSnapshot rebuild lists. Avatar request effects run because the array identity changed. Persist is skipped on heartbeat, but React work is not.

Console → LiveLog
Any console.log becomes a log entry, a 2000-item slice, and a React state update if LiveLog is mounted (console page, or home AgentsPanel when the player list is empty).

localStorage on the registry
Connect / update / list / status all call saveCachedPlayers synchronously. Size grows with unique agents (see M1).
